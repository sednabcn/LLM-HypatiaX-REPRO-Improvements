The transfer inventory is recorded in the repository-root `REPRO_TRANSFER_MANIFEST.tsv`. Original REPRO paths are retained so older references can be resolved.

Do not import archived scripts or outputs into the active pipeline without review, provenance checks, and an explicit promotion change in REPRO.
